\section{Purpose}

This CPU-only experiment isolates two mechanisms used by HG-MS when the
lower-level solution is non-singleton: (i) true unadjusted Langevin algorithm
(ULA) sampling followed by hard optimistic best-of-$N$ selection, and (ii) a
ridge-CG approximation to the pseudoinverse hyper-gradient.  Every analytical
quantity needed to check the implementation is available in closed form.

\section{Exact controlled problem}

Let $\theta\in[-3,3]$, fix the ambient lower-variable dimension $d=20$, and
vary the intrinsic minimizer-manifold dimension
$k\in\{1,2,4,10\}$.  Write
\[
 x=(y,z)\in\R^{k+1}\times\R^{d-k-1}
\]
and set $(\kappa,\mu,\epsilon,A,m,\rho)=(1,1,0.1,0.5,4,0.3)$.  Define
\[
\begin{aligned}
R(\theta)&=\sqrt{1+\theta^2},&
a(\theta)&=(\cos\theta,\sin\theta,0,\ldots,0)\in\R^{k+1},\\
c(\theta)&=\frac{R(\theta)}{\sqrt{1+R(\theta)^2}},&
u(\theta,x)&=
\frac{\langle y,a(\theta)\rangle}
{c(\theta)\sqrt{1+\lVert x\rVert^2}},\\
q_\theta(u)&=(1+\rho\theta)(u+1)
+A\sin^2\!\left(\frac{m\pi}{2}(u+1)\right).
\end{aligned}
\]
The lower and upper objectives are
\[
\begin{aligned}
g(\theta,x)
&=\kappa\!\left[
\sqrt{1+\bigl(\lVert y\rVert^2-R(\theta)^2\bigr)^2}-1
\right]+\frac{\mu}{2}\lVert z\rVert^2,\\
f(\theta,x)
&=2\sqrt{\epsilon^2+\lVert x\rVert^2}+q_\theta(u(\theta,x)).
\end{aligned}
\]
The lower minimizer set is the known $k$-sphere
\[
\mathcal S(\theta)
=\{(R(\theta)v,0):v\in\Sph^k\}.
\]
On this manifold, $u=\langle v,a(\theta)\rangle$.  Because
$1+\rho\theta\geq0.1$ on the full domain, the optimistic lower solution is
unique:
\[
x^\star(\theta)=(-R(\theta)a(\theta),0).
\]
It is non-degenerate intrinsically.  With the ambient-induced metric and any
orthonormal tangent basis,
\[
\operatorname{Hess}_{\mathcal S(\theta)}f(x^\star(\theta))
=\frac{1+0.3\theta}{1+\theta^2}I_k
\succeq0.01I_k.
\]

\input{OPTIMISTIC_HESSIAN_PROOF.tex}

The exact optimistic hyper-objective, hyper-gradient, optimizer, and optimum
are
\[
\begin{aligned}
F(\theta)&=2\sqrt{\epsilon^2+1+\theta^2},&
F'(\theta)&=\frac{2\theta}{\sqrt{\epsilon^2+1+\theta^2}},\\
\theta^\star&=0,&
F^\star&=2\sqrt{1.01}.
\end{aligned}
\]
Consequently, all reported quantities are exact:
\[
F(\widehat\theta)-F^\star,\qquad
\lvert F'(\widehat\theta)\rvert,\qquad
\lVert\widehat x-x^\star(\widehat\theta)\rVert_2.
\]

\section{HG-MS implementation}

At every outer update, HG-MS initializes $N=16$ independent branches with the
analyzed $\lambda$-scaled Gaussian warm start
\[
X_i^0\sim\mathcal N((2v_i,0),\lambda I_{20}),\qquad
v_i\sim\operatorname{Unif}(\Sph^k),\qquad \lambda=10^{-3}.
\]
The associated Gibbs law is
$\pi_\lambda(dx\mid\theta)\propto
\exp[-g(\theta,x)/\lambda]\,dx$.  HG-MS applies true ULA for $K=100$ steps
with $h=0.01$:
\[
X_i^{t+1}
=X_i^t-h\nabla_xg(\theta,X_i^t)
+\sqrt{2\lambda h}\,\xi_i^t,\qquad
\xi_i^t\sim\mathcal N(0,I_{20}).
\]
Hard optimistic selection returns
\[
\widehat x=\operatorname*{arg\,min}_{1\leq i\leq N}
f(\theta,X_i^K).
\]
At this selected point, matrix-free conjugate gradient starts at zero and
solves
\[
\bigl(\nabla_{xx}^2g(\theta,\widehat x)+\gamma I\bigr)v
=\nabla_x f(\theta,\widehat x),\qquad \gamma=0.3,
\]
to absolute residual tolerance $10^{-8}$ (at most 64 iterations).  The
resulting hyper-gradient estimator and projected outer update are
\[
\widehat h
=\nabla_\theta f(\theta,\widehat x)
-\nabla_{\theta x}^2g(\theta,\widehat x)v,\qquad
\theta^+=\proj_{[-3,3]}(\theta-\alpha\widehat h).
\]
HG-baseline uses the identical ULA, ridge-CG, warm start, and outer update with
$N=1$.

\section{Compared updates}

V-PBGD uses a stop-gradient auxiliary follower $\widehat\omega$ and jointly
updates $(\theta,x)$ on
\[
\Phi_V(\theta,x;\widehat\omega)
=s_f f(\theta,x)+s_g
\bigl[g(\theta,x)-g(\theta,\widehat\omega)\bigr],
\quad s_f=\min(1,\beta^{-1}),\quad s_g=\min(1,\beta).
\]
G-PBGD jointly updates $(\theta,x)$ on
\[
\Phi_G(\theta,x)
=s_f f(\theta,x)+\frac{s_g}{2}\lVert\nabla_xg(\theta,x)\rVert^2.
\]
IAPTT-GM differentiates exactly through
$x_{t+1}=x_t-\eta\nabla_xg(\theta,x_t)$ and uses the pessimistic truncation
$\bar t=\arg\max_{1\leq t\leq K}f(\theta,x_t)$.  The complete update-by-update
mapping, including all tuned constants, is in
\path{ALGORITHM_AUDIT.md} and
\path{results/pilot/selected_config.json}.

\section{Fairness and statistics}

Each method receives 60 single-thread CPU seconds for every
$(k,\mathrm{seed})$ pair, including initialization.  Final evaluation uses the
five held-out seeds $\{1000,\ldots,1004\}$ for every method and every $k$.
Method configurations are frozen before these runs using eight pilot
configurations per method, disjoint pilot seeds $\{11,28,47\}$, and validation
objective gap only.  The $k=10$ runs reuse the same frozen configuration and
are not retuned.  Independent $(k,\mathrm{seed})$ tasks may run concurrently,
but every individual method process is single-threaded.  The reported
uncertainty is mean $\pm$ symmetric bootstrap 95\% CI half-width from 5,000
resamples with bootstrap seed 82731.

\section{Mechanism diagnostics}

These diagnostics use controlled sample or iteration counts, rather than the
end-to-end wall-clock budget.

\paragraph{Selection error.}
For the hard best-of-$N$ candidate, the empirical squared distance to
$x^\star(\theta)$ is compared with finite-range Gauss--Jacobi quadrature of
the same order statistic.

\input{results/latex/selection_scaling_table.tex}

The observed slopes match the finite-range quadrature predictions and are
consistent with the sharper problem-specific $N^{-2/k}$ behavior, improving
on the conservative $N^{-1/k}$ upper bound proved in Lemma F.20.

\paragraph{Pseudoinverse, ridge, and CG errors.}
At an exact optimistic point, the pseudoinverse error is
\[
\left|
\nabla_\theta f-\nabla_{\theta x}^2g
(\nabla_{xx}^2g)^\dagger\nabla_xf-F'(\theta)
\right|.
\]
Ridge bias is the absolute difference between the dense ridge hyper-gradient
and the exact-pseudoinverse hyper-gradient at the same point.  CG solution
error is $\lVert v_{\mathrm{CG}}-v_{\mathrm{dense}}\rVert_2$ for the same
ridge system at a rotated non-optimistic manifold point.

\paragraph{ULA versus exact Gibbs.}
The reported MSEs compare the ULA-selected and independently exact-Gibbs-
selected hyper-gradient estimates with $F'(\theta)$ at
$k=2$, $\theta=1$, $\lambda=10^{-3}$, $h=0.01$, $K=100$, and $N=32$.
Their relative MSE difference is
$|\mathrm{MSE}_{\mathrm{ULA}}-\mathrm{MSE}_{\mathrm{Gibbs}}|
/\mathrm{MSE}_{\mathrm{Gibbs}}$.  The radial, angular, and normal
Kolmogorov--Smirnov values are one-dimensional marginal diagnostics only;
they do not establish the full R\'enyi-divergence guarantee.

\section{Reproduction}

From the repository root, run
\begin{verbatim}
python -m pip install -r synthetic_ula_ridge_cg/requirements.txt
bash synthetic_ula_ridge_cg/scripts/smoke_test.sh
RERUN_PILOT=0 JOBS=1 \
  bash synthetic_ula_ridge_cg/scripts/reproduce_all.sh
\end{verbatim}
The complete final protocol requires 6,000 CPU-seconds before mechanism-check
overhead.  Parallelism changes elapsed reproduction time but not the
single-thread per-method budget.
